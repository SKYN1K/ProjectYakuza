# Project Yakuza Phone (Dev) 0.1.4

Requires Project Yakuza 0.131.0 or newer. Enable both mods and choose Settings in the style wheel.

- The original phone angle and opening motion are preserved. The casing now has directional shading and restrained specular highlights driven by original surface normals and material-map samples, plus a soft shadow and a moving glass reflection. Original hardware geometry, UVs and diffuse pixels are unchanged. The lighting adapts the supplied maps to a normal Lua UI overlay; it does not port the original engine's full material shader. Coplanar source surfaces are merged for lighting, with at most 224 visible polygons and cached projection while still. Covered hardware and lighting stop drawing beneath opaque submenus. PZ's native UI3DScene remains orthographic.
- Opening uses Yakuza 6 console.acb's phone_open cue. Closing uses its phone_cancel01 cue. These replace generic menu open/close playback for the phone only and remain local to the listener. Original untrimmed waveforms are decoded without resampling, mixing or synthesis.
- Selecting Styles opens registered style names, descriptions and preview images, with equip, unequip and first/second slot assignment actions. Back returns to the phone. Equipping waits until the phone closes, and previews fade during that handoff. Styles without a supplied preview have a clear fallback. Addons may provide a previewImage texture path.
- Dragon of Dojima uses the supplied Kiryu_Zomboid.jpg image. Its complete composition is resized from 1280x720 to 512x288 with 128-colour PNG compression, reducing 50,896 bytes to 19,073 bytes. No generated artwork or upscaling. The texture is preloaded and checked through PZ's native PNG decoder.
- Controls reflect combat 0.131.0's single Heavy attack / finisher binding. Both actions use the same saved setting; the phone does not create another heavy binding.
- Offline validation passes 129,940 native projection, screen input, font, menu, style selection, local audio, modal transition and cleanup assertions; 3,510 native projection cases; original model/UV checks; 2,178,738 decoded pixels across 18 textures; and all nine production Lua modules compile. Original audio rates, channels, sample counts and PCM bytes match source; native sound definitions enforce non-positional one-shot playback. PZ was not launched, so live appearance and performance still need confirmation.

The install ZIP contains 31 runtime files only. Source reports, the supplied original image, tools, previews, private paths and credentials are excluded. presentation-assets.json records image and audio provenance; material-source.json records original material maps and lighting geometry.

# Project Yakuza Phone (Dev) 0.1.6

Requires Project Yakuza 0.133.0 or newer. Enable both mods and choose Settings in the style wheel.

- Handset labels are attached to the actual display plane: every font glyph follows the phone's angle, opening transition and pointer tilt. Uses the supplied PZ Noto Sans SemiBold font's unmodified atlas, proportional advances, offsets and kerning. Labels are composed as text; no individual label images are generated. Flat Styles, Items, settings and skills menus retain native Open Sans text. This handset-only projection was explicitly approved by the user; no Java helper is installed.
- Styles sort alphabetically, ignoring ASCII letter case, with stable ID ordering for equal names. The heart button and F key toggle per-character saved favorites without changing alphabetical order or assigning a slot. Heart artwork is an original Flaticon pack asset by Anggara; its visible credit appears in Settings and full provenance is in favorite-icon-source.json.
- Phone transforms reuse a single pose matrix instead of recalculating trigonometry for every vertex. Each lit casing polygon now uses one mathematically equivalent shade/specular composite draw instead of two. Pose geometry, glyph subtextures and text layouts remain cached, with bounded text caches and ready-texture guards. The original model, angle, diffuse material and creator previews are retained.
- The required shared combat update supplies the enlarged/varied limb smoke, revised charging effects, bounded first-use warm-up, movement/finisher corrections and low-health bar pulse.

Offline checks cover native phone projection, screen-parallel glyph edges, original proportional font metrics, cached labels, equivalent single-pass lighting, sorted names, saved/click/keyboard favorites, creator themes/previews, viewport bounds, Items interactions and cleanup. 64,230 phone Kahlua assertions and 3,510 native projection cases pass; 18 native texture decodes cover 2,105,010 pixels. Native imports and original font/icon pixels are checked; all 11 production Lua modules compile. Runtime-only packaging, source-comment checks and installed-byte verification precede publication. PZ was not launched; live visual quality and frame-time improvement are unverified.

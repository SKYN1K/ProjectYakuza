# Project Yakuza Phone (Dev) 0.1.5

Requires Project Yakuza 0.131.0 or newer. Enable both mods and choose Settings in the style wheel.

- Replaced manually rendered glyph images with PZ's native proportional Open Sans text renderer, native measurements and scalable regular/bold fonts. No custom glyph slicing or font texture is used. The removed Y6 bitmap font asset is backed up during installation. The original Y6 install supplies bitmap game font data rather than a compatible TTF/OTF; Open Sans is a supported approximation, not a claim to be the exact Y6 typeface.
- Rebuilt Styles around the actual viewport: measured wrapping, a scrollable description region, aspect-correct previews, responsive preview tabs and two slot buttons. Text, previews, buttons and footer have separate bounds. Below the preview, only Assign to 1st slot and Assign to 2nd slot remain; these assign without equipping or closing.
- The selected style supplies its theme through phoneMenu.theme. Dragon of Dojima defaults to light blue and retains its single supplied image without preview tabs. Creators can define accent, background and text colours.
- Creators can provide up to eight labelled image or timed-animation previews through phoneMenu.previews. The page reads complete registered style data, fixing the old metadata-only list that omitted creator presentation fields. Image and animation tabs appear only when multiple previews exist.
- Added Import-PhonePreview.py for author-supplied GIFs. It produces native PNG frames and a Lua descriptor with compositing, frame delays and loop counts preserved. Raw GIF files are not loaded by PZ at runtime. Playback supports variable frame delays, finite/infinite loops, cached next-frame loading and a ready-image fallback. Limits and examples are in STYLE_PRESENTATION.md. No GIF was supplied or added for Dragon.
- The existing phone material lighting, angle, health battery, real PZ skills, Items page and original local Y6 opening/closing sounds are retained. No combat, standalone-emote or voice-pack source changes.

Offline validation passed 62,197 Kahlua assertions and covers native Open Sans measurement/scaled-text bindings, 3,510 native model projection cases, viewport text bounds from 640x480 to 1920x1080, both slot assignments, creator themes, tab selection, variable frame delays, looping, loading fallback and cleanup. All ten production Lua modules compile; native pixel checks cover 16 UI textures / 1,580,722 pixels. Source-comment checks and runtime package privacy scans pass; installed bytes are verified during publication. PZ was not launched; live appearance and performance remain unverified. No author GIF was available for a full importer decode check.

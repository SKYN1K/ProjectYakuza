# Project Yakuza Phone development build

This optional add-on requires Project Yakuza 0.131.0 or newer. Combat, effects, settings and multiplayer code are shared with that mod. Enable both mods, then open the style wheel and choose Settings. Disabling the add-on restores the original settings menu after a restart.

The phone uses the supplied Yakuza 6 Xperia model, original UV layer 1, diffuse, icons and dragon wallpaper. PZ's existing UI3DScene draws its hardware, with projected screen content and inverse mouse input. Opening, closing and pointer tilt advance on rendered UI frames. The phone respects the chosen UI render rate and does not change global settings. No Java bridge is included. Native UI3DScene is orthographic; the world is dimmed rather than blurred. Original engine shaders and camera animation are not ported.

Latin text uses the original Yakuza 6 English gothic face 1. Its unchanged glyph coverage strip is converted from BC4 luminance to PNG alpha without resampling or upscaling. Original glyph regions follow the display plane; the right panel and Items page use the same font. Non-Latin glyphs use PZ's existing font atlas. Source hashes and conversion details are in font-source.json.

The phone has coloured original symbols on shaded pale plates, orange selection, original Heat orbs and a dark preview panel. Hovering over Items shows actual PZ skill levels and XP progress. Selecting it opens a categorized inventory with Weapons, Food, Medical, Clothing and Other tabs. Selecting a weapon performs PZ's native equip action after the phone closes; other items open the native item context menu. Main-inventory contents refresh every 1.5 seconds, and items are checked again before actions execute. The separate Skills app shows the same real skills. The battery represents overall character health with a percentage, proportional fill and red-to-green colour.

The Items transition uses the original Yakuza 6 pause_item scene's root opacity endpoints over ten frames, adapted to a 60 Hz UI clock with linear fades. Original interpolation type 2 has not been mapped to PZ. This adaptation is documented in items-source.json and does not claim to reproduce the full source scene.

Mouse wheel scrolls lists and is consumed while the phone is open. Arrow keys navigate; Tab changes focus; Enter selects; Escape returns or closes. In Items, left/right changes categories and Enter opens actions. Controllers use directions and A/B/Y. Closing, death, entering a vehicle, map opening, chat input, viewport changes, saving and leaving release the phone and its input focus. The world continues running. Advanced mod settings opens the original panel.

Textures warm up at game start and unready images wait before rendering. Glyph regions, text layouts, settled transforms, header values and inventory scans are cached. Live GPU appearance, model loading and performance still need in-game confirmation. PZ was not launched for validation.

Offline validation passed 129,940 Kahlua interaction assertions, 3,510 native projection cases, native geometry and UV checks, 2,178,738 native decoded pixels across 18 textures, source font/wallpaper/scene checks and compilation of all nine Lua modules. The runtime package contains 31 files. Documentation, extraction folders, previews, tools, local paths and credentials are excluded from the ZIP. See ICON_CANDIDATES.md for the separate Flaticon recommendation; the build retains supplied game icons.

The original hardware angle and opening motion are preserved. Directional shading and specular highlights follow the model surface normals and original material-map samples, with a soft shadow and a moving glass reflection. The original mesh, UVs and diffuse pixels are retained; native UI3DScene is still orthographic. The Lua lighting overlay adapts the original material response rather than porting the Dragon Engine shader. It draws at most 224 visible source polygons, caches settled projections and stops drawing beneath opaque submenus. See material-source.json for map hashes and the source geometry conversion. The dedicated Y6 phone_open and phone_cancel01 cues replace generic opening and closing sounds for the phone only, using local UI audio.

Press Styles to open style names, descriptions, previews and equip/unequip/slot actions. Dragon of Dojima uses the user-supplied image at 512x288, compressed to 19,073 bytes. Other registered styles may supply a previewImage texture path; a missing preview gets a text fallback. Up/down selects a style, left/right selects an action, Enter activates and Escape returns. Equip actions wait for the phone's closing transition; slot assignments stay on the Styles page. Source image and audio details are in presentation-assets.json.

The Controls app displays the core Heavy attack / finisher binding once, from the shared definitions. The same saved binding performs neutral heavy attacks, combo finishers and hold-to-charge input. Mouse/keyboard configuration remains in the main mod settings.

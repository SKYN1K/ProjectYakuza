# Phone icon recommendation

The closest base style I found is [Basic UI - Black fill by Anggara](https://www.flaticon.com/packs/basic-ui-268), a 120-icon pack. Its solid silhouettes suit Yakuza 6's coloured symbols on pale app plates. This is a visual recommendation based on the pack style, not a claim that every symbol below is included. The site's available listing did not expose all individual icon names. The [Color fill variant](https://www.flaticon.com/packs/basic-ui-270) is another option, although matching one colour per app gives more control over the Yakuza-like palette.

Proposed category mapping:

| App | Symbol to choose | Colour |
| --- | --- | --- |
| Styles | Two switching arrows | Orange |
| Items | Briefcase | Purple |
| Skills | Rising bars or a person with a chart | Green |
| Heat | Flame | Orange-red |
| Audio | Speaker | Blue |
| Effects | Sparkles | Magenta |
| Grabs | Open hand | Dark red |
| Controls | Gamepad | Gold |
| Settings | Gear | Grey |

Keep a consistent filled silhouette, a pale raised plate, a subtle shadow and orange selection. Avoid mixing outline, shaded 3D and filled icon families. The current build retains supplied game icons; no Flaticon files were downloaded or bundled. Individual symbol availability and the applicable download licence need checking before any future replacement.

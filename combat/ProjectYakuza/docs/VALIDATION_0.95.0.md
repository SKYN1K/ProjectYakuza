# Project Yakuza 0.95.0 validation

Project Zomboid was not launched. All six supplied original cmn.bin files were read offline. Five use the Yakuza 6 little-endian CMN18 layout; the Yakuza 5 crate uses big-endian CMN10. The parser checks bounds and final tree extent. Victim damage is filtered by the character ancestor; the crate's frame-13 prop damage is explicitly excluded. Source hashes, offsets, damage weights, frame maps and bank provenance are recorded in heat-scenes.json. The public format references are HActLib and vgmstream's CRI UTF reader, linked in that manifest.

validate_heat_scenes.py checks independently specified source/current contact lists for six main actions and two failure endings: 33 current contact entries. Bottle and wall weights preserve their previous total damage. Rush/crate keep the existing QTE-earned final aggregation, controls and prices. Ground has no CMN damage nodes and retains its verified frame-30 native sole/head contact. This is documented explicitly rather than presented as a source damage marker.

The real bank CueTable and CueNameTable resolve source cue IDs; CMN18 one-based indices and CMN10 zero-based IDs are checked. All 23 non-voice PCM16 WAV files match fresh vgmstream decodes byte for byte, including sample rate, channel count and sample count. The actual B42 GameSoundScript parser loads all 23 sound definitions and resolves their clip paths. Five existing katana source sounds retain their previous provenance check. Named Kiryu cues are routed through existing Combat voice entries; the separate voice pack is not edited or packaged.

Original blood-family starts and bone-local offsets reproduce 106 numeric native victim-bone anchors across eight clips. build_heat_scene_anchors.py verifies deterministic attachments using the retained native victim poses. build_heat_presentation.py imports all eight actor/victim pairs through native B42 Jassimp/FK and verifies 33 contact anchors, source-effect data and 50 unchanged clip onset measurements. build_attack_trails.py reproduces 83 active clips and 107 contact windows. These tools write numeric code/provenance only when requested. Original engine-specific gore emitters, non-blood particle systems, cameras and staging are not reproduced by the supplied PZ blood renderer.

Every one of the 1402 prior non-Lua media files matches the v0.94.0 ZIP byte for byte. No animation, texture, model or existing audio was modified. Katana source/native checks still verify all 141 samples, 6204 unchanged non-arm samples, original arm directions within 0.032 degrees, 564 native hand/prop pose pairs and eight native owner/victim/observer selectors. The release/catch/reversed grip remains intact, with final sharp-axis alignment 0.9584; the previous rigid grip fails the negative regression.

All 30 rebuilt Kahlua suites pass in separate bounded JVMs: blood, charged UI, CVF combat, directional, encounter, exertion, extension API, starter addon, Extreme attacks, grab, Heat audio, paired damage, Heat presentation, Heat Rush, Heat shove, Heat speed, input prompts, low health, MP, punch effects, quickstep, repair, sound options, sound variety, style entry/items/selector, taunt and weapon/weapon MP. The expanded presentation suite checks all six main timelines and both failure endings, exact independent sound/voice/effect starts, duplicates, stale-frame dropping, failure clock switching, invalid ending authoring, custom fallback, rotation and cleanup. MP checks exercise source-weighted bottle contacts, server-derived damage and replay suppression. Startup/payment and lethal deferral remain covered through production handlers. All 77 production Lua files compile. The source-comment scanner finds zero comments; its six lexical regression tests pass.

Installation verifies the complete previous installed release before writing, backs up only changed existing files and verifies the complete resulting byte set. Publishing uses the dedicated release script and a fresh v0.95.0 tag. The versioned ZIP, local source, installed files and GitHub asset digest are compared. Extraction folders, probe outputs, backups and credentials remain outside Git and the ZIP. Live rendered appearance, game audio mixing and real network latency still require a gameplay check after restarting with matching updated server/client copies.

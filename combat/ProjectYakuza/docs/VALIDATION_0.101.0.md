# Project Yakuza 0.101.0 validation

Cleanup is limited to confirmed obsolete runtime files and duplicate numeric code. It preserves current gameplay and every retained animation/model/texture/audio byte. Project Zomboid was not launched.

The audit treats engine-loaded XML as asset roots and includes all animation names in normal nodes and blend entries. Thirty custom weapon-pose/ordinary-walk selectors require animation variables that have no production Lua producer; they have been disabled since 0.78.0. Removing those unreachable selectors leaves 56 .x motions with no surviving selector or Lua reference. The removed families are old carry/ready/idle/movement conversions, footwork slices, moving stance and superseded victim hold/walk clips. Every retained custom clip has a live reference. The restored RMB combat idle and current Lost Judgment entry remain.

Texture reachability includes literal Lua paths, dynamically assembled source frame sequences, model texture declarations and engine-resolved item icons. It retains 96 HeatWisp frames, 64 ExtremeHeat flame frames, 64 smoke frames, 16 blood frames and all current static UI/effect/item/model textures. The 171 retired textures belong to superseded WorldHit, TauntAura, Bar animation, QTE/effect, wisp-only and StyleFX outputs. All 263 retained PNGs match baseline decoded dimensions, modes, alpha and every pixel; their complete file bytes are unchanged.

The sole unreferenced sound definition is ProjectYakuza_Y6_ChargeEnd. Its act_kiryu_003.ogg has no other script reference and is removed with that definition and its unused sound-menu label. All 111 surviving audio files still resolve from sound declarations and retain exact bytes. Dynamic sound variety pools and current scene/menu/style/activation audio remain. No voice-pack files are changed.

The first-light track duplicated the generated dd_trail_light01_1 data under an unused legacy key. AttackTracks is now the registry initializer; the generated catalogue supplies the data. The punch fixture uses the active key and verifies all 31 shoulder/elbow/hand/knuckle FK samples against the native original clip, along with 66 retained source textures, audio and projection. The public registry, addon templates and independent style APIs remain.

The removal ledger records 258 exact baseline paths, byte counts, SHA-256 hashes and reasons. The reference validator checks all remaining Lua requires, native selector animation names, dynamic frame paths, textures and sounds. A negative regression restores an exact retired selector, confirms publication validation rejects it, then checks that the opt-in pruner removes only that audited output. Publishing invokes the read-only validator before building its archive. Baseline byte comparison is an explicit audit option, allowing later authorized asset updates while keeping reference/retirement checks active.

All 30 rebuilt Kahlua suites pass and all 83 production Lua files compile. All 167 retained .x files import through native JAssImp/ProcessedAiScene. Both MP observer cycles retain 450 matching event-free nodes. Current combat-entry/RMB/armed fallback checks pass. Source-comment scanning reports zero comments and all six lexical tests pass. Historical source/conversion metadata remains provenance for active builds and earlier releases; obsolete full-payload pose checks are superseded by the current cleanup/reference/native checks.

Installation verifies the complete v0.100.0 baseline, backs up only changed/deleted existing files, removes only the exact ledger paths and verifies the full final file set. Publishing uses a fresh v0.101.0 tag/release with an install ZIP; source/installed/archive bytes, remote asset digest and tag commit are verified. No game runtime, movement, damage, input, asset synthesis or model/texture conversion is introduced.

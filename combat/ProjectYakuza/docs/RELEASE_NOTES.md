# Project Yakuza 0.124.0

- Removed the extra 56-pixel displacement introduced in 0.123.0, which the user observed moving arm smoke to foot level. The earlier camera-only reconstruction did not validate the complete game rendering path, and its alignment conclusion is withdrawn.
- Applied the user's requested approximate 10%-below placement using the compact outer-smoke base height as the reference. This is a 2.176-pixel screen drop at B42 tile scale 2, shared by every coating layer and captured by limb-emitted sparks. World coordinates and depth are unchanged. Charging effects use the same small drop; source Heat Action/blood anchors receive no synthetic camera translation.
- Reduced outer smoke diameter by about 35% and the inner core by about 21%; the middle Gaiden wisp and small limb sparks are also smaller. Original game textures, layered translucency, colours, bounded swirl, short tails and particle budgets are retained. Partial-weight leg effects remain enabled.
- Offline checks pass 23,931 limb/clock/lifecycle assertions, including the 10% basis, tile scaling, common placement across all layers, size bounds, hand sparks and every catalogued kick/stomp at multiple weights. Native engine bone/world projection is checked for 23,232 cases over sixteen facings; this verifies coordinate math, not final rendered placement. Blood/source-anchor, paired presentation, charging and multiplayer checks pass; all 89 production Lua files compile. Source comments, runtime references, package privacy, changed-file backups and installed bytes are verified. All existing media files remain byte-identical. No new visual/audio assets, game launch or preview. Exact live hand alignment remains unverified; this release uses the user's requested approximation.

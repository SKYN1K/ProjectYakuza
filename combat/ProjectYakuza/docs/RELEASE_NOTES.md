# Project Yakuza 0.113.0

- Added a native Project Yakuza Sandbox Options page with Dragon style Tiger Drop enabled by default, a 10-1000 ms timing window defaulting to 160 ms, a 0-600 second cooldown defaulting to 20 seconds, and independent Heat Actions, grabs and Extreme Heat switches. Fractional cooldown seconds and zero cooldown are supported. Missing options keep existing behavior and malformed values use safe defaults or limits.
- Client action requests and multiplayer authority enforce the same settings. Disabled actions do not reserve a target or consume Heat. Feature changes safely release active grabs, paired scenes and Extreme Heat protection. The Tiger Drop HUD respects its toggle. Addon counter timings retain their own defaults. Weapon Heat Actions remain usable during Extreme Heat, spending the existing stock/fuel costs, and outside it.
- Replaced missing and obsolete settings text with clear audio, keybind, menu and QTE labels. All 99 registered sounds and all three categories have readable Advanced Sound Options names. Native keybind conflict messages resolve this mod's captions while other bindings remain delegated. Saved option and sound identifiers remain stable.
- Install and Workshop packages now use an explicit game-file allowlist. Development docs, provenance reports, templates, tools, backups and AGENTS.md are excluded. Runtime text, media metadata and archive names are checked for personal paths and credential patterns. The local install removes the old development/support payload after backing up the exact replaced/removed originals. Existing media assets are unchanged.
- Offline validation passes all 32 Kahlua suites, six packaging/privacy/label tests, native parsing of all six sandbox options, native Workshop content validation, production Lua compilation, runtime references and the zero-comment gate. Tests include configured counter timing/cooldown, independent switches, disabled-action no-payment behavior, active-mode cleanup, multiplayer rejection and all six weapon Heat Action profiles during Extreme Heat. No Project Zomboid launch or Steam Workshop upload is performed.

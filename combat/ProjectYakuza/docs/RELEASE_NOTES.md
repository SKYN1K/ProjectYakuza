# Project Yakuza 0.129.0

- Restored cool-white limb effects and replaced the inner flame stamps with independently animated original smoke. The fuller, enlarged outer layers keep their hand/foot anchors, controlled transparency and short shrinking tail. The existing 48-sprite budget is unchanged.
- Fixed opaque black impact rectangles: the original e_j_0332 spark sheet contains fully opaque black pixels and now uses additive rendering. Original transparent smoke sheets retain ordinary alpha blending. Source pixels are unchanged.
- Impacts alternate between radial, narrow directional, compact and split-fan silhouettes, with varied speeds, curves, lifetimes, sizes and original smoke mixes. The original Gaiden hit-smoke joins the contact burst. Successful new contact effects replace the repeated legacy star/glint stamp; blood and guard feedback remain.
- Visual reference: SEGA's Yakuza 6 Ultimate Heat screenshot (https://ryu-ga-gotoku.com/six/assets/img/battle/battle03/ss-06.jpg) and Gaiden charge-attack screenshot (https://ryu-ga-gotoku.com/gaiden/asia_en/battle/img/btl03_01.jpg). The adaptation uses soft pale contact smoke, directional sparks and a brief central flash, rather than reproducing the original engine's shaders or screen-space treatment. The requested limb colour remains white.
- Offline validation passed 29,888 limb/projection/variation/lifecycle assertions and 818 blood/contact/multiplayer-budget assertions, native original-pixel and source-clip checks, and all 91 production Lua modules. Source-comment and runtime package checks precede installation and publication. No game launch or generated artwork; live appearance still needs an in-game check.

# Project Yakuza 0.127.0

- Reworked Dragon-style hit presentation with larger cyan cores, deeper blue mid layers, two soft animated smoke shells and more lively small embers. Limb effects increase from 30 to 48 sprites, with independently phased source frames, breathing sizes and bounded swirl. Bright cores/sparks use scoped additive drawing; smoke remains translucent.
- Impacts now combine twelve flying sparks, three staggered original soft puffs and a short contact flash. Recorded hand/foot motion biases the spark direction, alongside varied curves, velocities and lifetimes. Strong/charged hits gain size and longer spark flight. Smoke puffs stay short, and the 65ms limb tail tapers and shrinks instead of leaving a large ending cloud.
- Preserved the corrected standing/walking-parent prediction and existing small cosmetic placement. Visual size no longer changes that placement. All weapon contacts, kicks, throws and Heat Actions share the presentation; pause/map hiding, interruption cleanup and renderer-state restoration are retained. Eight actors, eight trails, four impact bursts per actor and twenty-four globally bound the AttackEffects component to at most 960 sprites.
- Uses only original assets already supplied in the mod. No texture/model/motion/audio file is generated or changed. The phone development build will use this same combat dependency and effect implementation.
- Offline validation includes 29,861 limb/effect assertions, the native parent-pose regression suite, native sprite-scale/original-pixel checks and combat presentation/charging/multiplayer checks. Production Lua compilation, comment/reference/package checks and changed-file backup/installed-byte checks are required before release. No game launch or visual preview; visual appearance and in-game performance still require a live check.

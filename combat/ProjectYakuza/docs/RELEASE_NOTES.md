# Project Yakuza 0.125.0

- Fixed a native B42 sprite-size rule affecting the Gaiden arm wisp and two Kiwami 2 impact wisps. The engine forced their 64x128 textures to 2x scale after calculating placement at the requested small scale, making them both oversized and displaced down/right. Runtime width metadata and horizontal scale compensation bypass this rule while preserving original pixels, UVs, aspect ratio, dimensions and centred placement. No new assets or Java bridge.
- Reduced ending smoke: the outer coating tapers towards the hand and shrinks during a 45ms fade, replacing the previous 70ms fixed-size tail. Impact puffs are about 41% smaller in diameter, less opaque, shrink as they fade and disappear within 95ms. Core visibility, limb tracking, the requested small downward placement, colours, sparks and particle budgets remain intact.
- Offline validation reproduces the engine's scale override and verifies the correction through normal Kahlua-exposed texture and sprite methods against the installed native renderer. Limb/effect checks pass 23,958 assertions, including native-size-rule simulation, original aspect ratio, endpoint taper and ending-smoke limits. Native bone/world coordinate checks cover 23,232 cases over sixteen facings. All 70 original effect textures / 309,248 pixels pass native channel/orientation checks; source media remain byte-identical. Blood, paired presentation and charging checks pass, all 89 production Lua files compile, and source-comment, runtime-reference and package checks pass. Local changed-file backups and installed bytes are verified during installation. No game launch or generated preview; final live hand alignment still needs in-game confirmation.

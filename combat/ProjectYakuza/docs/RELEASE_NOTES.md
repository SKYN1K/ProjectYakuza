# Project Yakuza 0.115.0

- The bicycle breaks at the confirmed final crushing impact, source frame 70 (2.333 seconds), instead of after the five-second recovery. It reaches zero condition and its held model hides at impact; the original break cue and three supplied wheel/handlebar parts play at the victim position. The action retains only that exact broken bicycle until recovery finishes, then unequips it and restores prior model visibility. Cancelling before impact preserves the bicycle; cancellation after impact retains its broken condition and cleans up normally.
- Multiplayer confirms breakage on the server's final-contact packet. Predicted hit-feedback deduplication cannot skip destruction; native condition sync arriving before the contact acknowledgement cannot cancel the owner's recovery. Later pose packets reconcile model visibility for observers, and completion remains a fallback. Duplicate packets do not replay break effects. Condition changes suppress the native duplicate break sound.
- Equipping the bicycle in either hand restricts movement to walking, including when no combat style is selected. Native run/sprint permissions and queued forced-run flags are cleared while carrying it. Unequipping restores the player's prior run and sprint permissions independently; save and world-exit cleanup restores them too.
- Fixed local installation precedence: obsolete ProjectYakuza Workshop staging folders are archived outside Zomboid's load paths. The normal install and single current Workshop stage are checked byte-for-byte. Published Workshop item metadata is preserved, unrelated mods stay untouched, and repeated installation is idempotent. The release publisher now runs this installer unless explicitly skipped.
- Offline validation: all 33 Kahlua suites pass, including impact timing, full broken-weapon recovery, owner condition/contact ordering, authoritative snapshots, movement input restrictions, replay protection and cleanup. All 89 production Lua files compile; native B42 input-permission, model-visibility and silent condition-update APIs are checked. Package/privacy and installer regression tests pass, and source comments are absent. Existing animations, models, textures, item scripts and sound assets remain unchanged. Project Zomboid was not launched.

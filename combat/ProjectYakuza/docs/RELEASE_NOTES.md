Weapon strikes follow the wielding arm; source-pose overrides select the raised kicking leg, stomp foot, wall punch/kick and throw grip/release. Bottle Heat Actions use the swinging right arm.

Heat Action presentation keeps tracking through gaps between contacts and gates QTE strikes with the existing local acceptance / replicated confirmation data. This uses baked source-bone positions, without a runtime Java bridge; final engine blending can still produce small differences.
- Added original Kiwami 2 aura wisps, streak sparks and a spark fan, layered with the existing Yakuza 6 flame/glint pixels. Brighter pulsing coats and six short flying sparks make confirmed hits more lively. Spark colour matches the limb effect, flight varies between hits and emitted particles remain in world space while the actor moves or turns. Typical limb windows span 60 ms before to 120 ms after contact, with 120 ms tails. Bursts are limited to three per actor and sixteen total; pause, map visibility, interruption and world transitions cleanly handle every layer. No game animation, model, audio, gameplay damage or network packet format changes.

# Project Yakuza 0.126.0

- Corrected limb prediction for masked ordinary attacks. PZ renders these clips over the standing/walking pelvis or spine, while the old effect curves assumed the attack's complete body pose. The first punch and ordinary bat, bottle, knife, blade and boosted punches now inherit the active base pose's rotation and position instead of retaining the discarded source body parent.
- Predicts base parents from 445 original native Human clips using current layer-zero clip names, clocks and effective blend weights. The actual XML body masks select the pelvis or spine boundary. Shoulder, elbow, wrist and palm coating, short trails and limb-emitted impact sparks share the corrected pose. Full-body kicks, throws and Heat Actions keep their original source prediction. The compact smoke, requested small cosmetic drop, partial-weight leg visibility, effect budgets and map/pause suppression are retained.
- No Java bridge, new artwork, sound, model or motion asset. Only numeric code-side parent curves are derived from supplied originals. All existing runtime media and animation selectors remain byte-identical to 0.125.0.
- Offline validation passes 107,739 assertions over 2,213 native parent poses and 168 actual AnimationPlayer layered-pose cases, including six masked attacks, three underlying poses and a weighted two-pose blend. Maximum tested corrected model-position error is below 0.00001, compared with an original mismatch reaching 0.575 model units. Another 23,982 limb/effect assertions include the first punch's corrected shoulder/elbow/palm in eight facings. All 91 production Lua files compile; original-pixel, native sprite-scale, blood, paired presentation, charging, multiplayer, source-comment, reference and runtime-package checks pass. Installation backs up changed existing files and verifies every installed byte.
- No game launch or generated preview. These native checks verify the tested full-weight masked pose and coordinate math; final in-game placement, partial attack blends, procedural body twists and unknown third-party base animations remain unverified.

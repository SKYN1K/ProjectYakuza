# Lost Judgment blue Dragon combat entry

Version 0.100.0 uses the installed Lost Judgment dod moveset mod's blue Crane/Dragon Engine style entry, p_yag_btl_sud_styl_mai_st.gmt. All 151 samples are retained at the original 60 fps, lasting 2.5 seconds. The supplied Dragon Engine c_man skeleton is the body reference for conversion to native PZ proportions; source body rotations, arm directions and native finger/prop grips are preserved.

The prior Kiwami conversion placed the pelvis at ground level and the feet below the floor. The new conversion measures the native skinned foot soles against Bob_Idle and applies only the required vertical root correction per original support frame. Native validation checks all 151 foot placements, a pelvis height above 0.469 native units and source/body/hand transforms. It does not add poses or alter the original frame rate.

The entry remains stationary, movement and attacks stay locked during playback, and the character remains vulnerable. The full source clip releases through a 0.3-second fade. Scoped cleanup preserves foreign actions. Relaxed idle remains vanilla Bob_Idle. While RMB is held with the unarmed style token, the previous ProjectYakuza_DD_CombatIdleLoop returns through the exact aim and aim-strafe selectors from v0.98.0. Supported real weapons and other styles retain their native aim selection. The retained idle motion itself is unchanged.

combat-entry-assets.json records the installed mod source/hash, native references, all sample times, support-foot measurements, root corrections, output hash and restored idle selector hashes. build_lj_entry.py reproduces the conversion; validate_combat_entry.py checks source poses, grounding, native imports/FK and actual entry/relaxed/RMB/armed selector behavior. The earlier Kiwami builder and provenance describe the superseded entry. Live blends still need gameplay assessment after restarting.

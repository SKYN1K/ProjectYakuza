# Project Yakuza 0.107.0 validation

The three cutscene emotes are removed from the combat mod and moved into the independently installable Project Yakuza Emotes 0.1.0 addon. Eight runtime files are removed: two Lua modules, three native animations and three emote selectors. Four emote translation entries and the bundled-emotes description are removed. Nine emote-only guides, provenance reports and historical validation records move to the addon. No combat behavior or existing combat animation is changed.

Split validation checks zero emote runtime references in combat and byte-identical preservation of all 1242 retained motion, selector, texture, model and audio files against 0.106.0. Majima/Kiryu animation/selector bytes remain unchanged. The separate addon extends Lau by 75 original source frames and adds 22 native spear calibrations, all verified by independent source/native probes. The three source/native motion validators still pass in their new location. The addon has its own ID/namespace/category, requires no combat/CVF module, and retains an optional combat-active-action guard.

All 31 Kahlua suites pass, including 173 standalone/combat coexistence emote assertions. The actual native menu without either optional mod and both native/CVF hook load orders pass 20 assertions each with combat absent. All 83 combat Lua files compile, and the two standalone Lua files compile separately. Zero source comments and all six lexical tests pass. Combat asset/reference validation reports 167 clips, 263 textures, 115 audio files and 258 retired assets absent. No source texture conversion is performed.

The local migration verifies the installed 0.106.0 ZIP baseline, backs up only changed or removed existing files, removes the exact retired file list and installs byte-verified combat 0.107.0 plus the separate addon. Both ZIPs are verified against the complete corresponding source/installed file sets and published as separate versioned releases in the private repository. The addon is enabled independently in the mod list. Project Zomboid is not launched; live visual/MP playback remains untested.

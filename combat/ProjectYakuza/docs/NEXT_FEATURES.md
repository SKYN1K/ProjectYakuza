# Extension opportunities

Current native combat, defense, heat, taunt/entry/activation, audio/visuals, custom controls and MP observers are covered in [the manual](INDEX.md). New styles and move kinds can be independent API-2 addons.

Grabs remain temporarily disabled. Cinematic heat actions/cameras, direct ragdoll impulses, a Java bridge, gamepad/split-screen UI and PvP parity need separate implementation. New paired mechanics require server validation/cleanup in addition to supplied animations.

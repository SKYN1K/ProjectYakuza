# After the shared combat stance

0.11.1 uses a stationary Kiryu idle and a single moving upper-body stance over native directional legs, as requested. Running attacks use native locomotion exit before submitting melee.

Guard/block remains the next defensive candidate. Kiryu guard start/loop/end and directional head/body/leg clips exist locally. Correct blocking also needs incoming-attack interception, direction rules, stamina cost and interruption handling. Timed parries need incoming-attack timing and successful-defense reactions. Grabs, throws and heat actions require paired alignment and synchronization and remain a larger step.

# Project Yakuza Emotes 0.2.1 validation

The original Kiwami main16_s02 archive, CMN16 scene, cut 012 resource table, main16_012_1 motion and Kiwami skeleton are freshly extracted and compared byte-for-byte with the conversion inputs. Full hierarchy sampling retains center_c_n translation, which the existing in-place body conversion intentionally removes. Its relative planar displacement is normalized to frame zero, rotated by the existing source yaw and scaled using the same source/native pelvis-height ratio. All 220 samples remain at 30 fps over 7.3 seconds.

Only Translation_Data translation changes in the animation. The other 34 body/finger channels, Translation_Data rotation and scale, all sample times and original native sole grounding match the 0.2.0 release exactly. No poses, visual/audio content, textures, models or sounds are synthesized. Texture/pixel checks are therefore not applicable.

The Step Up selector explicitly selects Translation_Data with Y as the vertical axis, enables deferred movement and disables deferred rotation. The native JAssImp/B42 importer retains 35 shared Human channels and the complete original duration. The parsed native selector, full-body/root movement weights, isolated emote condition, native cancellation, replicated EMOTE/PLAYING parameters and single EmoteFinishing event pass offline checks. No custom network protocol, Java bridge, Lua coordinate writes, movement lock or collision bypass is introduced.

StepUpMotionProbe integrates the actual native AnimationTrack at every original sample. Its displacement matches the source path within 0.00002 native units, with zero rotation and no new motion on paused, finished or stopped tracks. The full source path ends at approximately 0.173009, -0.382744 native planar units. Normal native collision handling can restrict the actual gameplay displacement.

The Kahlua emote suite passes 191 assertions; the installed native menu alone and each pinned CVF provider order pass 24 assertions. Native baseline validation preserves all existing non-Step-Up emote animation/selector bytes and all combat media. Both production Lua modules compile. Source-comment and lexical checks run before publication.

Local installation verifies the complete 0.2.0 addon against its release ZIP before replacing changed files, backs up only changed existing files, then verifies every installed byte against source. Combat source and installation remain byte-identical to combat 0.108.0. The standalone ZIP is compared against source and installation, followed by its uploaded digest and release commit. Project Zomboid is not launched. Live foot blending, obstacle interaction and multiplayer remain untested in gameplay.

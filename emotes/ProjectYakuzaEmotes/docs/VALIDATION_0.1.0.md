# Project Yakuza Emotes 0.1.0 validation

Majima and Kiryu retain byte-identical native animation and selector files from Project Yakuza combat 0.106.0. Independent source extraction, original GMT/CMN/resource bindings, native Human import, full-body masks, sole grounding and original weapon calibration pass for Majima's 152 samples, Lau's extended 154 and Kiryu's 355. Lau appends 75 original cut-008 frames after the exact cut-007 boundary, adding 2.5 seconds for 5.1 seconds total. All 22 native spear items have model-specific shaft/floor calibration. Native bone lengths and source wrist/weapon rotation remain intact; a bounded two-bone arm clearance below 0.088 native units prevents the low sweep from intersecting the floor. All 3388 model/frame combinations, 6776 native hand/prop pairs and all 22 native Human imports pass. Maximum strike contact error is below 0.0000001 native units. No new texture, model or audio content is generated. The native animation identifiers are preserved as asset names; there are no aliases or compatibility loaders.

The addon uses its own mod ID, Lua namespace, translation keys and native wheel category. Its two Lua modules compile independently and require no combat module or CVF. All 22 native spear items and their indexed sprites are covered. Unknown modded spear SubCategory/SwingAnim weapons are accepted through the crafted-spear fallback; their custom mesh alignment remains unverified. Actual B42 classification methods are verified offline. Native emote cancellation and replicated emote parameters remain unchanged. The only optional combat integration reads the existing active-action map at selection time when combat is present, preventing an emote from interrupting an active combat action. The addon creates no combat global or state.

The emote suite passes 173 checks, including loading without a ProjectYakuza global, standalone empty-hand dispatch, every existing weapon/safety rule, optional combat-action rejection, menu rebuilding and native delegation. The actual native menu without either optional mod and both installed B42/pinned CVF provider load orders pass 20 checks each with combat absent. All 31 standard Kahlua suites pass across the workspace. The combat mod's 83 Lua files and addon's two Lua files compile separately. Source-comment checks report zero comments and all six lexical tests pass.

Split validation checks that the main mod contains none of the emote Lua hooks, translation keys, selectors or animation assets, and that all 1242 retained combat media files remain unchanged. Combat reference validation reports 167 clips, 263 textures, 115 audio files and 258 retired assets absent. The standalone package contains two original emotes plus 22 calibrated spear clips/selectors, has no required mod dependency, and adds no textures, sounds or models; no pixel conversion is applicable.

Local migration verifies the complete installed combat 0.106.0 file set against its ZIP before changing files. It backs up changed or removed existing files, removes only the exact retired emote file list, installs combat 0.107.0 and the separate emote addon, and verifies every final byte against source. Separate release ZIPs are checked against those same source/installed file sets and their uploaded digests/tag commits. Extracted game data, previews, framework and the separate voice pack remain excluded. Project Zomboid is not launched. The addon must be enabled separately; live visual blending and multiplayer still need gameplay testing.
